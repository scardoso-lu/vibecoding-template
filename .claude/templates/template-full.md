# Full Feature Template Index

This file is intentionally small. Do not put category-specific template bodies here.

In Plan Mode, read `.claude/templates/template-routing.md` first, then load only the category templates required by the current slice.

Normal non-minimal feature memory produces one slice per business feature plus a shared global rules library:

```text
feature-memory/
  rules/
    <category>.md      # global rules library, shared across features; each block cites its slug
  <feature>/
    slice.md           # one business feature; links siblings + rules in ## Dependencies
    e2e-coverage.json  # user-facing features only; maps initial prompt stories to Playwright tests
    qa-evidence.json   # generated by scripts/validate/gate.py after deterministic checks run
```

The category templates provide sections to compose into each feature's `slice.md`. The rules category template composes the shared `feature-memory/rules/<category>.md` files - the only rules output. There is no per-slice `rules.md`.
