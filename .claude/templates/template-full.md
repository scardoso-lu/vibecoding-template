# Full Feature Template Index

This file is intentionally small. Do not put category-specific template bodies here.

In Plan Mode, read `.claude/templates/template-routing.md` first, then load only the category templates required by the current slice.

Normal non-minimal memory produces PRDs, ADRs, one slice per business feature, and a single global
rules file:

```text
memory/
  rules.md             # global rules, shared across every feature; one block per guideline slug
  PRD/<purpose>/prd.md # product intent
  ADR/<purpose>/adr.md # architecture decision
  feature/
    <feature>/
      slice.md           # one business feature; links PRD/ADR/siblings/rule slugs in ## Dependencies
      e2e-coverage.json  # user-facing features only; maps initial prompt stories to Playwright tests
      qa-evidence.json   # generated by scripts/validate/cli.py gate after deterministic checks run
agent-evidence/
  prompt-N/
    agent-evidence.json # prompt interpretation records, prompt hash, x_request_id, hashed by scripts/validate/cli.py agent-evidence-hash
```

The category templates provide sections to compose into each feature's `slice.md`. The rules category template composes the single shared `memory/rules.md` - the only rules output. Rules are never split by category, and there is no per-slice `rules.md`.
