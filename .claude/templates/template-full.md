# Full Feature Template Index

This file is intentionally small. Do not put category-specific template bodies here.

In Plan Mode, read `.claude/templates/template-routing.md` first, then load only the category templates required by the current slice.

Normal non-minimal feature memory produces one slice per business feature plus a single global rules file:

```text
feature-memory/
  rules.md             # global rules, shared across every feature; one block per guideline slug
  <feature>/
    slice.md           # one business feature; links siblings + rule slugs in ## Dependencies
    e2e-coverage.json  # user-facing features only; maps initial prompt stories to Playwright tests
    qa-evidence.json   # generated by scripts/validate/gate.py after deterministic checks run
```

The category templates provide sections to compose into each feature's `slice.md`. The rules category template composes the single shared `feature-memory/rules.md` - the only rules output. Rules are never split by category, and there is no per-slice `rules.md`.
